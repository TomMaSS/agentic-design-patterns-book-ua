## 📚 Про книгу

**Agentic Design Patterns: Практичний посібник зі створення інтелектуальних систем** — це фундаментальний посібник із проєктування та розробки агентних AI-систем. Книга є практичним керівництвом для розробників, архітекторів та дослідників, які працюють у сфері штучного інтелекту.

### 🎯 Основна мета

Книга зосереджується на патернах проєктування, які дозволяють спеціалізованим агентам працювати разом і співпрацювати для досягнення складних цілей. Кожен розділ представляє унікальну парадигму співпраці та взаємодії між AI-агентами.

### 🚀 Ключові особливості

- **Практичний підхід**: Реальні приклади коду та робочі рішення
- **Структуроване викладення**: Від базових концепцій до просунутих технік
- **Сучасні технології**: Огляд останніх досягнень у сфері агентних систем
- **Багатоагентні архітектури**: Фокус на співпраці та координації агентів

## 🚀 Технологічний стек

Книга охоплює сучасні технології та фреймворки:

- **LangChain** — для створення ланцюжків промптів
- **CrewAI** — для багатоагентної співпраці
- **RAG (Retrieval-Augmented Generation)** — для витягу знань
- **MCP (Model Context Protocol)** — для управління контекстом
- **Просунуті техніки промптингу** — для оптимізації взаємодії
